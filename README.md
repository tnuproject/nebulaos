## 🌌 Overview

**NebulaOS** is an independent Linux-based operating system powered by a customized GNOME desktop environment, Libadwaita interfaces, and deep native mobile integration via **MyNebula**. Designed with an obsession for detail, smooth animations, cohesive squircle iconography, and an uninterrupted silent boot pipeline.

---

## ✨ Key Features

### 🖥️ Native Libadwaita & GTK4 Applications
- **Settings App (`nebula-settings`)**: Complete control center featuring real-time Wi-Fi management, display & brightness adjustments, audio device selectors, emergency SOS & medical profile configuration, and an integrated GitHub-powered OTA system updater.
- **Camera (`nebula-camera`)**: Fast, modern photo and video capture built on GTK4 and GStreamer with automated fallback pipelines.
- **Gallery (`nebula-gallery`)**: Responsive image viewer with smooth animations, zoom controls, and canvas sketching tools.
- **Calendar & Clock (`nebula-calendar`, `nebula-clock`)**: Clean, distraction-free productivity utilities.

### 📱 MyNebula Companion Ecosystem
Connect your Android phone directly to NebulaOS without third-party cloud servers:
- **Instant Screen Mirroring**: Start wireless, low-latency screen mirroring directly from the phone app; NebulaOS opens a dedicated desktop window streaming your phone's display in real time.
- **Notification Mirroring**: Push phone notifications directly to the desktop (`notify-send`) so you never miss an alert.
- **PetalDrop File Sharing**: Instant peer-to-peer wireless file transfer between your computer and mobile devices.
- **Cloud Photo Sync**: Browse and sync your desktop's photo library right from your phone.

### 🔄 Automated GitHub OTA System Updates
- Update your entire operating system right from **Settings > Software Updates**.
- **Channel Support**:
  - **`stable`**: Only delivers validated, official releases.
  - **`delta`**: Delivers bleeding-edge pre-releases generated by continuous integration.
- Instant, partial delta updates packaged as standard deb packages for high reliability and zero system breakage.

### 🎨 Visual Polish & Silent Boot
- **Seamless Boot**: Custom GRUB configuration silences low-level console text for an OEM-like boot splash.
- **Hatter & Nebula Icon Themes**: Crisp, custom-crafted squircle icons across third-party and built-in apps.
- **Curated Celestial Wallpapers**: High-resolution default backgrounds with automated lock-screen blur generation.

## 🚀 Building from Source

### Prerequisites
- Ubuntu 22.04 / 24.04 or Debian 12 (or WSL2 with Ubuntu)
- `sudo` privileges

Install build dependencies:
```bash
sudo apt-get update
sudo apt-get install -y --no-install-recommends \
  dpkg-dev gzip xorriso grub-pc-bin grub-efi-amd64-bin \
  mtools squashfs-tools dosfstools e2fsprogs gettext-base \
  python3 python3-pip
```

### 1. Build the Bootable Live ISO
To produce a hybrid bootable ISO (`.iso`) compatible with UEFI, Legacy BIOS, and tools like Rufus or `dd`:
```bash
sudo bash scripts/patch_and_rebuild_isos.sh
```
The output image will be generated under `build/output/NebulaOS-26.0-Apollo-x86_64.iso`.

### 2. Generate a Standalone OTA Package
To create a delta `.deb` package and update metadata:
```bash
./scripts/create_ota_update.sh 26.0.1 "Feature updates and bug fixes"
```

## 🤖 Continuous Integration & Automated Releases

This repository includes a GitHub Actions workflow (`.github/workflows/build_and_release.yml`):
- **On Push to `main`**: Automatically compiles and publishes a **`delta` (pre-release)** containing both the hybrid ISO and the partial `.deb` OTA package.
- **Manual Trigger (`workflow_dispatch`)**: Choose between `stable` and `delta` channels, assign a version tag, and provide custom changelog notes to publish official stable releases.
